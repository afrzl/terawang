# Kebijakan harga gabah

`hpp_gkp_petani.csv` — riwayat Harga Pembelian Pemerintah (HPP) **GKP di tingkat petani**, Rp/kg, 2015–2026. Kolom: `berlaku_mulai` (YYYY-MM-DD), `hpp_gkp_petani_rp_kg`, `dasar_hukum`, `sumber_url`, `catatan`, `jenis` (`hpp` = HPP resmi; `fleksibilitas` = harga beli sementara Bulog di atas HPP, lewat Rakortas/Keputusan Kepala Bapanas).

Ringkas HPP resmi: Inpres 5/2015 Rp3.700 (17 Mar 2015) → Permendag 24/2020 Rp4.200 (19 Mar 2020) → Perbadan 6/2023 Rp5.000 (24 Mar 2023) → Perbadan 4/2024 Rp6.000 (±5 Jun 2024; sudah berlaku sejak 3 Apr 2024 sebagai fleksibilitas Kepbadan 167/2024) → Kepbadan 2/2025 Rp6.500 (15 Jan 2025) → Kepbadan 14/2025 Rp6.500 tanpa rafaksi (24 Jan 2025). Tidak ditemukan perubahan s.d. Nov 2026.

Belum terverifikasi ke teks resmi (hanya berita): fleksibilitas 2017–2018 (tanggal per bulan; angka 2017/Jun 2018 = 110% × 3.700, hitungan), 2022 (tanggal mulai beda antarsumber, dicabut 17 Okt 2022), SE 47/2023, SK 62/2023, Kepbadan 167/2024, 2/2025, 14/2025. Tanggal undang Perbadan 4/2024 dari berita dan metadata berkas.
